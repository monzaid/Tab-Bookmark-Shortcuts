# 标签页书签快捷切换插件：约束层（权限与隐私）

- 日期：2026-07-14
- 状态：待用户确认后进入架构层

## 权限模型

扩展在安装时请求 `<all_urls>` 页面访问权限，不提供按需授权模式。该权限用于让自动标题/favicon 重写规则能立即在任意普通网页上运行。安装页、商店描述与设置页须清晰说明全站访问的用途与边界。

基础能力还需要浏览器标签页、窗口、存储和通知相关权限，以支持跨窗口切换、同步配置、恢复交互提示等需求。

## 受保护页面边界

浏览器内部页和受保护页面（如 `chrome://`、`edge://`、大多数 `about:`、扩展商店、扩展页面）可作为槽位目标并支持切换与插件 UI 标记。

标题/favicon 重写规则只允许普通网页 URL。规则编辑时拒绝受保护页面范围，避免承诺浏览器无法提供的注入能力。

## 隐私/无痕窗口

默认不访问隐私/无痕窗口。只有用户在浏览器扩展管理页显式允许无痕访问时，插件才将其中标签页纳入保存、匹配、切换和标题/favicon 重写；未获授权时必须排除。

## 失效恢复交互约束

快捷键触发后无法可靠打开工具栏弹窗，跨浏览器通知按钮行为也不一致。因此，目标失效时统一打开专用、紧凑的扩展恢复页面/窗口，提供：

1. 打开保存的 URL；
2. 切换至下一个匹配 URL 的现有标签页；
3. 什么都不做。

前两项成功时自动更新对应槽位绑定。

## 配置迁移与数据处理

配置导入/导出仅通过用户主动操作的明文 JSON 文件进行；不上传到任何服务。导入前必须展示配置摘要并要求确认，避免意外覆盖。

## 图标来源、存储与网络边界

支持 URL 图标、本地上传图标和“背景色 + 文字”的模板矢量图标。

- 模板相关配置可同步。
- 本地上传图标压缩、限尺寸后保存到 `storage.local` 为 data URI，不同步文件内容。同步或导入到其他设备时展示“本地图标缺失”占位，并要求用户重新选择文件。
  - **澄清（2026-10-04）：导出 ≠ 同步，但导出同样不搬运位图字节。** 导出文件只承载三类图标：① `Icon URL`（纯字符串）；② `local-icon` **引用占位**（导入方据此显示"缺失"并要求重新选择）；③ **可复现配方**（背景色 / 文本或 Emoji / 文本色，渲染时还原）。**任何原始位图 data URI 都不入包**——URL 缓存图标由接收方"首次需要时建立本地缓存"（即上一条既有边界）。因此无需体积上限、无需"附带图标数据"开关。此澄清**不改变**同步路径——同步永不携带 data URI。详见 `2026-10-04-import-export-constraint-boundaries-design.md`。
- 远程 URL 图标在设置时下载、压缩并缓存至本地；后续 UI 只读缓存，不在展示时向第三方发请求，也不自动更新。
- 同步配置保留远程图标源 URL，本地缓存不参与同步；新设备在首次需要时建立本地缓存。
- 下载、格式校验或压缩失败时，保留 URL 配置并显示占位图；用户可从设置页手动重试，插件不进行自动后台重试。

## 关键取舍

- 全站权限换取任意正则自动生效和更简单一致的跨浏览器模型，代价是安装时必须透明说明隐私影响。
- 图标缓存优先保护用户的使用时机隐私和离线可用性，代价是不自动跟随远程图标更新。
- 恢复流程使用扩展页面而非通知按钮/工具栏弹窗，换取 Chrome、Edge、Firefox 的一致行为。
