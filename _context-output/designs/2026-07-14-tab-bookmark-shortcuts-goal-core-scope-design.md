# 标签页书签快捷切换插件：目标层设计

- 日期：2026-07-14
- 状态：待用户确认后进入约束层

## 已确定的目标

首版开发跨浏览器 WebExtensions 插件，兼容 Chrome、Edge 与 Firefox。插件使用浏览器声明式命令实现快捷键驱动的标签页书签保存和快速切换。

## 成功范围

1. 提供 10 个预置槽位，每个槽位有“保存当前标签页”和“切换到槽位”两个命令；实际快捷键由浏览器扩展快捷键管理页配置。
2. 槽位保存会话 `tabId`、精确 URL、标题与 favicon 快照；用户可将精确 URL 改为或补充为正则 URL 规则。
3. 匹配策略支持全局默认和槽位覆盖：
   - 会话标签优先；
   - 会话标签加规则校验（默认）；
   - 严格规则匹配。
4. 目标未找到时显示恢复弹窗：打开保存 URL、切换至下一个匹配 URL 的现有页，或不操作；选择前两项会自动更新槽位绑定。
5. 多个规则匹配页时，优先当前窗口，再按标签栏从左到右、其他窗口随后；提供独立“下一个匹配标签页”命令以循环候选项。手动选择器仅在扩展弹窗或设置页中打开。
6. 标题/图标采用双层识别：页面级修改 `document.title` 和 favicon；插件级在弹窗和设置页显示自定义标题、图标与颜色标签，并在切换时通知。两个界面均支持编辑、解绑和修改绑定，以及直接编辑当前标签页的标题与图标。
7. 配置优先使用浏览器同步存储，并支持导入/导出，以覆盖跨浏览器和同步故障迁移。
8. 已占用槽位在保存时直接覆盖，提供短暂撤销提示。

## 首版明确不包含

不支持槽位分组/排序、云端账号、多用户共享、标签页会话历史和自动规则推荐。

## 被拒绝的方向

- 仅 Chromium：不满足从首版起跨浏览器兼容的目标。
- 只配置切换快捷键：不满足快捷键保存当前页的核心需求。
- 仅页面改写或仅插件标记：无法同时获得稳定识别和页面内增强。
- 固定回退策略：不足以覆盖不同失效场景。
- 为每槽位增设手动选择快捷键：命令负担过重。

## 后续待决

隐私与权限范围、跨浏览器 API 降级、恢复弹窗承载方式、配置导入格式与冲突处理、正则安全性、页面改写的执行边界和错误处理、测试与发布策略。
