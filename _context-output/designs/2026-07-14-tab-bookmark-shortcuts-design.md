# 标签页书签快捷切换插件：完整设计文档

- 日期：2026-07-14
- 状态：待用户最终审批

---

## 1. 概述

首版开发跨浏览器 WebExtensions 插件，兼容 Chrome、Edge、Firefox。插件使用浏览器声明式命令实现快捷键驱动的标签页书签保存和快速切换。每个浏览器实例内支持多窗口标签页查询与切换；不支持浏览器之间互相发现或切换标签页。

---

## 2. 核心功能

### 2.1 快捷键槽位

- 提供 10 个预置槽位，每个槽位有“保存到槽位 N”和“切换到槽位 N”两个命令，共 20 个槽位命令。
- 额外提供 1 个“下一个匹配标签页”全局命令。
- 实际快捷键由浏览器扩展快捷键管理页配置；插件设置页显示命令状态与跳转指引。

### 2.2 槽位绑定

每个槽位保存：
- 会话 `tabId`（本地运行时状态）；
- 精确 URL 或正则 URL 匹配定义（同步持久配置）；
- 标题与 favicon 快照；
- 插件 UI 标记（自定义标题、图标、背景色，仅影响侧边栏/设置页展示）。

精确 URL 规范化比较：忽略锚点，主机名小写，移除 HTTP/HTTPS 默认端口；路径与查询参数严格相等。

正则使用 JavaScript `RegExp`，最大 500 字符；编辑时校验语法、代表性 URL 试运行和风险提示。运行时每个可访问标签页 URL 至多匹配一次，始终检查全部标签页。

### 2.3 匹配策略

三种策略，全局默认 + 槽位可覆盖（显式继承模型）：

| 策略 | 行为 |
|------|------|
| A. 会话标签优先 | `tabId` 存在即切换；否则按 URL/正则查找 |
| B. 会话标签 + 规则校验（全局默认） | `tabId` 存在且 URL 仍匹配才切换；否则按 URL/正则查找 |
| C. 严格规则匹配 | 忽略 `tabId`，仅按精确 URL 或正则规则查找 |

### 2.4 多候选排序与循环

- 优先当前窗口，再按标签栏从左至右，随后其他窗口。
- 切换槽位定位首个匹配页。
- “下一个匹配标签页”以最近成功切换的槽位为上下文，按本地循环游标继续。

### 2.5 失效恢复

目标标签页不存在时，打开小型独立弹出窗口，提供：
1. 打开保存的 URL；
2. 切换至下一个匹配 URL 的现有标签页；
3. 什么都不做。

恢复窗口操作时重新查询实时标签页状态。选择 1 或 2 成功后自动更新本地 `tabId` 绑定和最近恢复快照（URL、标题、favicon），不修改原槽位精确 URL/正则匹配定义。关闭、取消或 5 分钟超时视为不操作，静默删除恢复会话。

### 2.6 页面标题与图标重写

页面重写规则系统与槽位系统相互独立。

- 规则支持精确 URL 或正则匹配，默认自动运行，可切换为仅手动应用。
- 自动规则仅在页面加载完成或 URL 变化时执行一次；不持续监听或恢复被网站覆盖的标题/favicon。
- 多个规则命中时按优先级数值（-100 至 100，默认 0）降序，再按创建时间降序选择。
- 规则冲突采用保守校验：明显冲突阻止保存；不可判定重叠二次确认后允许保存。
- 仅手动规则从设置页打开跨窗口候选列表，用户选择目标应用。
- 删除规则后不主动恢复页面 DOM；刷新或跳转后网站自行恢复。

### 2.7 tabId 临时个性化

按当前 `tabId` 的会话级标题/图标覆盖：
- 仅在该标签页实例存活期间有效；关闭或重启即清除。
- 字段级部分覆盖，优先级：tabId 临时覆盖 → 页面重写规则 → 网站原始值。
- 移除后提示刷新或跳转可恢复自然状态。

### 2.8 图标来源

- URL 图标：设置时下载、压缩并缓存至本地；后续 UI 只读缓存，不自动更新。
- 本地上传图标：PNG/JPEG/WebP，原文件最大 2 MB、最大边长 512 px；压缩为最大 128×128 px、64 KB 的 WebP data URI，仅保存于 `storage.local`。
- 模板图标：背景色 + 文字合成。
- 本地图标不同步；跨设备显示占位并提示重新选择。

## 3. 架构

### 3.1 运行模块

- **Service Worker**：响应 21 个命令，执行匹配、跨窗口激活、恢复会话管理、缓存与单一配置写入。
- **内容脚本**：在可注入普通网页的 `document_start` 静态注入；只上报初始和 SPA 导航，接收最小标题/favicon 改写指令。
- **React + TypeScript 多入口 UI**：侧边栏、设置页、恢复窗口、导入预览页、候选选择器。
- **最小 WebExtensions 适配器**：封装命令、标签页、窗口、存储、页面脚本、通知和无痕访问能力。

### 3.2 存储分层

| 存储 | 内容 |
|------|------|
| `storage.sync` | 槽位定义、URL/正则、匹配策略、UI 标记、页面重写规则、规则优先级、全局默认策略、配置版本 |
| `storage.local` | `tabId` 绑定、循环游标、最近成功槽位、恢复会话、本地图标缓存、tabId 临时个性化、最近恢复快照 |

Service Worker 以内存缓存提高性能，启动时或缓存缺失时读取存储，通过 `storage.onChanged` 更新/失效缓存。

### 3.3 消息协议

类型化请求/响应协议：共享 `action`、载荷、成功结果与领域错误码。UI 按错误码展示提示，不暴露原始浏览器错误。

### 3.4 配置一致性

所有配置写入经 Service Worker 单写入服务，提交携带递增配置版本做乐观校验。版本不一致返回冲突错误，UI 要求刷新重试。跨设备接受浏览器同步的最后写入胜出，并在下次打开 UI 时提示外部变更。

### 3.5 状态清理

- 监听 `tabs.onRemoved` 清理对应 tabId 绑定与临时个性化。
- 创建/访问恢复会话及 Service Worker 启动时清理 5 分钟过期会话。
- 启动时验证所有保存 tabId 是否仍存在。

### 3.6 构建与发布

单一代码库，浏览器专属 manifest 覆盖构建 Chrome/Edge MV3 包和 Firefox 兼容包。

## 4. 权限与隐私

- 安装时请求 `<all_urls>` 页面访问权限。
- 基础权限：标签页、窗口、存储、通知。
- 受保护内部页（`chrome://`、`edge://`、多数 `about:` 等）可作为槽位目标切换，但标题/favicon 重写规则仅允许普通网页 URL。
- 默认不访问隐私/无痕窗口；用户手动授权后纳入全部功能。
- 配置仅本地明文 JSON 导入导出，不上传任何服务。
- 本地诊断日志仅记录时间、领域错误码、浏览器类型、操作类型；不含完整 URL、页面标题或规则内容。

## 5. UI 设计

### 5.1 侧边栏（主界面）

工具栏按钮仅用于打开/聚焦侧边栏。侧边栏默认跟随当前活动标签页，顶部支持锁定当前 tabId。

布局：
1. 当前标签页面板（页面规则卡片 + 仅此标签页卡片）
2. 10 个槽位卡片列表（空/已绑定状态分层）
3. 创建页面重写规则入口
4. 设置页、导入/导出、诊断入口

### 5.2 设置页

独立浏览器标签页，左侧固定导航：
1. 槽位与快捷键
2. 页面重写规则
3. 全局匹配策略
4. 导入导出
5. 诊断

### 5.3 关键交互

- 已绑定槽位覆盖保存：侧边栏保持打开，显示 5 秒撤销条。
- 上下文切换保护：存在未保存编辑时确认“保存草稿 / 丢弃 / 留在当前页”。
- 破坏性操作按风险分级确认。
- 页面内统一轻提示 + 重要事件系统通知。
- WCAG 2.1 AA 基础无障碍。

## 7. 首版明确不包含

槽位分组/排序、云端账号、多用户共享、标签页会话历史、自动规则推荐、高对比度/大字号专属无障碍模式。
