# 标签页书签快捷切换插件：细节层（UI、校验与交互）

- 日期：2026-07-14
- 状态：待用户确认后进入汇总审批

## 主入口与侧边栏

工具栏按钮只负责打开或聚焦侧边栏，不使用传统扩展小弹窗。Chrome/Edge Side Panel 与 Firefox Sidebar 的差异由适配层处理。

侧边栏默认跟随当前活动标签页；顶部支持锁定当前 tabId 以持续编辑该页。锁定目标关闭时自动解除并提示回到跟随模式。

侧边栏布局采用当前标签页优先：

1. 顶部当前标签页面板；
2. 10 个槽位卡片列表；
3. 创建页面重写规则入口；
4. 设置页、导入/导出与诊断入口。

当前标签页面板以并列卡片清晰分离两种作用域：

- 页面规则：持久配置，按当前完整 URL 初始化，作用于后续匹配页；
- 仅此标签页：基于 tabId 的临时个性化，关闭标签页或浏览器重启后失效。

两张卡片均显示状态、作用范围、已覆盖字段和编辑/移除操作。

## 槽位交互

固定展示 10 个统一卡片：

- 空槽位显示编号、空状态和“保存当前页”；
- 已绑定槽位显示图标、标题、背景色、匹配摘要和“切换”主操作；
- 覆盖保存、编辑 UI 标记、解绑、候选列表等位于更多菜单。

保存到已绑定槽位时立即覆盖，侧边栏保持打开并显示 5 秒撤销条，包含被替换旧绑定摘要；撤销由后台恢复旧配置，超时后不可再撤销。

全局匹配策略与槽位覆盖采用显式继承模型：全局页设置默认策略（已定为“会话标签 + 规则校验”）；每个槽位明确显示“继承全局”或其独立覆盖策略，并可恢复继承。

## 设置页与规则编辑

设置页为独立浏览器标签页，不嵌入侧边栏。左侧固定导航：

1. 槽位与快捷键；
2. 页面重写规则；
3. 全局匹配策略；
4. 导入导出；
5. 诊断。

规则完整编辑对话框仅在“页面重写规则”分区打开。侧边栏仅做快速规则编辑（当前 URL 初始化、标题/图标、自动/手动、保存）；正则、优先级、冲突详情和删除在设置页完成。

规则编辑采用分级内联校验：即时检查 JavaScript 正则语法、500 字符上限和明显冲突；明显冲突阻止保存。潜在但不可判定的重叠在提交时进入二次确认，列出可能冲突规则、双方优先级和生效影响，确认后保存并在列表中保持提醒。

“仅手动应用”的规则从设置页打开跨窗口候选列表，由用户选择一个实时匹配标签页执行。

## 快捷键、导入与图标

“槽位与快捷键”页列出 20 个保存/切换命令与“下一个匹配页”命令，显示浏览器返回的按键或“未设置”，提供跳转浏览器快捷键管理页的按钮及按 Chrome/Edge/Firefox 区分的说明。

导入合并采用统一预览表格：对每个冲突槽位并列展示现有/导入摘要，用户逐项选择保留现有或采用导入，并可一键全选任一方向，确认后一次性提交。本地图标按缺失占位导入，不参与恢复。

图标 UI 支持 URL、本地上传、背景色 + 文字模板。上传仅允许 PNG/JPEG/WebP，原文件最大 2 MB、最大边长 512 px；保存前压缩为最大 128×128 px、64 KB 的 WebP data URI，并显示预览。UI 明确提示本地图标仅保存本设备，导入/同步到其他设备须重新选择。

## 恢复窗口与删除确认

失效恢复采用小型独立弹出窗口，显示槽位摘要、失效原因和三个选项。完成、取消、用户手动关闭或超过 5 分钟超时均自动关闭；关闭/超时视为不操作，删除会话，不产生额外提示或待办。

破坏性操作按风险确认：

- 槽位解绑、持久页面规则删除须二次确认，并说明未来停止匹配/改写；
- tabId 临时个性化移除立即执行，提示刷新或跳转后网页会恢复自然状态；
- 删除本地图标缓存须确认，仅删缓存、保留来源配置并显示占位。

## 草稿、反馈与无障碍

侧边栏在存在未保存编辑内容时，用户切换标签页、解锁/重新锁定或关闭侧边栏，将确认“保存草稿 / 丢弃 / 留在当前页”。草稿不触发改写，只有显式保存才生效。

侧边栏、设置页和恢复窗口使用统一、可关闭且可被屏幕阅读器播报的页面内提示条展示成功、失败、保存、导入结果。跨窗口切换、恢复成功回绑、无目标和后台失败仍按既定策略发送系统通知。

UI 满足 WCAG 2.1 AA 基础要求：颜色状态同时使用文本/图标，控件有可访问名称、键盘导航与可见焦点，主要文本和关键提示符合 AA 对比度。
