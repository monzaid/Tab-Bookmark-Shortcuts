# 标签页书签快捷切换插件：UI/UX 视觉与交互设计

- 日期：2026-07-14
- 状态：UI/UX 设计深化中（尚未进入实施计划）
- 适用范围：Chrome、Edge、Firefox 的侧边栏主界面、独立设置页、恢复弹出窗口与候选选择器

## 1. 设计方向

### 1.1 产品气质

采用“浏览器原生效率工具”方向：可信、低干扰、信息密度高，同时在需要理解作用范围或作出确认的区域提供清晰卡片层级。

- 默认跟随系统浅色/深色主题。
- 功能强调色使用中性蓝 `#2563EB`。
- 槽位自定义色仅承担个人识别，不代替成功、警告或错误等系统状态。
- 完全使用系统字体栈：`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`。
- 首版遵循 WCAG 2.1 AA 基础无障碍要求。

### 1.2 层级策略：混合型

| 区域 | 视觉策略 |
|---|---|
| 槽位列表 | 原生工具感：中性表面、细分隔、约 8px 圆角、无/低阴影、紧凑扫描 |
| 当前页规则 / 临时个性化 | 强卡片层级：约 12px 圆角、清晰范围说明和状态标签 |
| 恢复窗口、规则编辑对话框、导入冲突预览 | 提升表面、柔和阴影、明确操作区，强调决策任务 |
| 设置页 | 固定导航 + 工具栏 + 表格 + 详情抽屉，避免过度卡片化 |

## 2. 主题与设计令牌

### 2.1 语义色彩

| 用途 | 浅色主题 | 深色主题 |
|---|---|---|
| 主强调/活动操作 | `#2563EB` | `#60A5FA` |
| 主按钮前景 | `#FFFFFF` | `#0B1220` |
| 焦点环 | `#93C5FD` | `#1D4ED8` |
| 成功 | 语义绿 | 浅语义绿 |
| 警告 | 语义琥珀 | 浅语义琥珀 |
| 错误 | 语义红 | 浅语义红 |
| 文字、表面、边框 | 以语义 token 映射，随系统主题切换 | 以语义 token 映射，随系统主题切换 |

槽位颜色提供 12 色预设色板，并允许高级用户以 HEX/取色器选择自定义色。保存前检查对比度并提示；对比度不足不阻止保存，但会建议调整，并自动选择可读的图标前景色。槽位颜色只用于 3–4px 左侧色条和图标圆底。

### 2.2 字体与密度

- 页面标题：20px / 600
- 分区标题：14px / 600
- 槽位标题、按钮：13–14px / 500–600
- URL 摘要、辅助状态：12px / 400
- 徽标、微标签：11px / 600

### 2.3 图标与动效

- 常规导航/操作图标：圆角线性图标，约 1.75px 描边。
- 成功、警告、错误、需恢复、无痕未授权等：实心语义图标 + 短文本。
- 图标尺寸：行内操作 16px，导航/按钮 18px，关键状态 16px。
- 只保留 120–160ms 淡入、折叠展开、焦点/悬停过渡；无位移、弹跳、循环或装饰性动效。
- `prefers-reduced-motion` 下取消或即时化全部动效。

## 3. 主入口与侧边栏

### 3.1 打开方式与上下文

工具栏按钮只负责打开或聚焦侧边栏，不显示传统扩展小弹窗。

- 默认：跟随当前活动标签页。
- 可选：侧边栏顶部锁定当前 tabId，持续编辑该页。
- 锁定目标关闭后：自动解除锁定，切回跟随模式并提示。

### 3.2 响应式边界

| 宽度 | 行为 |
|---|---|
| 基准 320px | 当前页摘要、双卡片、紧凑槽位行完整可用 |
| <300px | 隐藏槽位普通次级摘要，仅保留异常状态与主操作；顶部卡片纵向堆叠 |
| >=440px | 顶部双卡片改为双列；槽位行显示更完整匹配摘要和快捷键状态 |

### 3.3 布局结构

1. 可折叠的当前页摘要；
2. 并列的“页面规则”与“仅此标签页”卡片；
3. 10 个槽位紧凑列表；
4. 创建页面重写规则入口；
5. 设置页、导入/导出、诊断入口。

### 3.4 当前页摘要

默认收起，仅显示 favicon、原始标题（单行截断）和“跟随当前标签页 / 已锁定”。

展开后显示：完整 URL、所属窗口、tabId 会话状态、当前生效页面规则、临时覆盖关系。该区域为只读确认与诊断信息，不混入编辑状态。

## 4. 当前页自定义卡片

### 4.1 固定作用范围文案

- 页面规则：`适用于匹配此 URL 的页面，可长期保留`
- 仅此标签页：`只作用于当前标签页，关闭后自动移除`

### 4.2 情境引导

两张卡片视觉权重相同，主操作随状态变化：

| 状态 | 页面规则 | 仅此标签页 |
|---|---|---|
| 无配置 | 创建页面规则 | 仅自定义此标签页 |
| 已有规则 | 显示匹配摘要、自动/手动、优先级，编辑规则 | 可创建临时覆盖 |
| 已有临时覆盖 | 显示规则仍存在；命中时标明被覆盖 | 突出“正在覆盖规则”，编辑 / 移除 |
| 两者都有 | 显示持久规则当前未生效原因 | 显示覆盖字段与会话生命周期 |

### 4.3 快速编辑

侧边栏内采用卡片行内展开：

- 基础字段：自定义标题、图标预览、自动/手动（仅页面规则）、保存/取消。
- 图标来源（URL / 本地上传 / 模板）收纳为二级展开区。
- 正则、优先级、冲突详情、删除只在设置页处理。
- 保存后当前标签页立即应用页面规则填写的字段。
- 切换标签上下文、解锁/重新锁定或关闭侧边栏前如有未保存内容，确认：保存草稿 / 丢弃 / 留在当前页。草稿不触发任何改写。

## 5. 槽位紧凑列表

### 5.1 单行结构与尺寸

每行高度 48–56px：

`[编号] [左侧细色条 + 图标圆底] [标题/未绑定] [状态] [主操作] [更多]`

- 左侧 3–4px 色条为槽位唯一强色彩标记，行底保持中性。
- 标题单行截断，完整值在 tooltip 中展示。
- 当前、悬停、键盘聚焦用中性表面高亮、边框或焦点环表达；不改变槽位颜色语义。

### 5.2 操作模式

- 空槽位：右侧始终显示 `保存当前页` 文字按钮。
- 已绑定槽位：整行点击或 `Enter` 触发切换；右侧仅保留更多菜单图标。
- 悬停/键盘聚焦：显示“切换”提示及命令快捷键；未配置时显示“快捷键未设置”。
- 焦点顺序：行 → 更多菜单；Escape 关闭菜单。

### 5.3 状态层级

- 正常：低调显示 `已绑定` 或匹配摘要。
- 多匹配：数字徽标，例如 `3`；tooltip 说明排序及循环行为。
- 异常：图标 + 短文本，例如 `需恢复`、`无痕未授权`。
- 完整原因：tooltip、屏幕阅读器文本、更多菜单中的“查看详情”。

覆盖保存时侧边栏保持打开，显示包含旧绑定摘要的 5 秒撤销条。

## 6. 设置页

独立浏览器标签页，左侧固定分区导航：

1. 槽位与快捷键；
2. 页面重写规则；
3. 全局匹配策略；
4. 导入导出；
5. 诊断。

### 6.1 页面重写规则分区

顶部工具栏：

- 左：搜索框；
- 中：筛选器（全部 / 自动 / 手动 / 有冲突）；
- 右：主按钮 `新建规则`。

主体为紧凑表格 + 右侧详情抽屉：

`状态 · 匹配范围 · 改写字段 · 运行方式 · 优先级 · 操作`

详情抽屉展示完整 URL/正则、标题与图标覆盖字段、优先级、冲突依据、图标来源、当前命中结果及编辑入口。完整规则编辑对话框只在该分区内打开。

### 6.2 规则校验与确认

- 即时校验 JavaScript 正则语法、500 字符上限、明确冲突。
- 明确冲突阻止保存。
- 不可判定的潜在重叠触发二次确认，展示关联规则、双方优先级和高优先级生效影响。

## 7. 候选选择器与恢复窗口

### 7.1 候选选择器

按窗口分组紧凑展示：当前窗口优先，随后其他窗口；每组显示窗口名称/编号、当前窗口标记和匹配数量。组内严格按标签栏从左至右排列。

候选行显示 favicon、标题、URL 摘要及当前标签标记。默认焦点为排序第一项。

确认方式按风险区分：

- 槽位候选查看、恢复页切换：单击或 Enter 即立即切换。
- 手动应用页面规则：单击仅选中，底部显示规则摘要和即将改写字段；用户再点击 `应用到此页` 确认。

### 7.2 恢复窗口

使用小型独立弹出窗口，显示槽位摘要、失效原因与三个操作。完成、取消、用户关闭或 5 分钟超时均自动关闭；关闭/超时视为不操作，不产生额外通知或待办。

## 8. 反馈、确认与无障碍

- 侧边栏、设置页、恢复窗口统一使用可关闭、可被屏幕阅读器播报的页面内提示条。
- 系统通知仅用于跨窗口切换、恢复成功回绑、无目标和后台失败。
- 槽位解绑、持久规则删除、本地图标缓存删除按既定风险级别二次确认；tabId 临时个性化移除立即执行并提示刷新/跳转后的恢复边界。
- 所有图标按钮有可访问名称、tooltip 和可见焦点；颜色从不作为唯一状态传达方式。
