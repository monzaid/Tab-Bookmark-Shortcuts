# 标签页书签快捷切换插件：约束层深挖（当前标签页自定义）

- 日期：2026-07-14
- 状态：待用户确认后进入架构层

## 弹窗中的两类自定义边界

扩展弹窗中“自定义当前标签页标题、图标”的主要入口创建或更新独立页面重写规则：以当前完整 URL（包括路径和查询参数）初始化精确匹配，用户可在编辑页显式改为正则。规则保存后立即将已填写字段应用到当前标签页；后续则遵循自动/手动规则的执行设置。

槽位 UI 标记仍保持独立：只作用于扩展的槽位列表，不修改网页。

## tabId 临时个性化

另提供按当前 `tabId` 创建的标签页实例级标题/图标个性化：

- 仅在该标签页实例存活期间有效；标签关闭或浏览器重启即清除。
- 当前 tabId 覆盖优先于命中的持久页面重写规则；移除覆盖或标签页关闭后，页面可再次按持久规则处理。
- 标题和图标均支持字段级部分覆盖；未设置的字段按“tabId 临时覆盖 → 页面重写规则 → 网站原始值”继承。

## 移除/删除后的页面状态

不主动恢复页面 DOM。删除页面规则或 tabId 临时覆盖后，只阻止未来重写；当前页面保留最后一次已写入的标题/favicon，直至刷新或跳转。删除操作必须提示用户：刷新页面可让网站恢复自然状态。

## 关键取舍

- 精确完整 URL 作为新规则默认匹配范围，降低用户从当前页面创建规则时意外影响整站的风险。
- tabId 覆盖是会话级例外，不持久化到未来相同 URL 页面；长期需求应显式使用页面重写规则。
- 不保存/还原 favicon DOM 快照，换取更小的复杂度和更可预测的动态站点边界。
