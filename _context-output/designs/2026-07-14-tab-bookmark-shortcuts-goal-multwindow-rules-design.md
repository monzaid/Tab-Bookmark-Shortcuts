# 标签页书签快捷切换插件：目标层深挖（多窗口与视觉规则）

- 日期：2026-07-14
- 状态：待用户确认后进入约束层

## 新增目标决策

### 单窗口与多窗口体验

单窗口高频工作流和多窗口/多显示器工作流同等优先。首版验收须覆盖：

- 跨浏览器窗口激活并聚焦目标标签页；
- 候选标签页列表清楚展示窗口归属；
- 失效绑定恢复流程在跨窗口场景下可用。

### 槽位与标题重写规则相互独立

槽位系统与网页标题重写规则系统为两套独立配置。新建槽位会从当前标签页初始化匹配信息，但之后可独立演进。

槽位的自定义标题、图标和背景色为插件 UI 标记，仅展示在扩展弹窗和设置页，绝不修改网页的 `document.title` 或 favicon。

网页级 `document.title` 和 favicon 改写只由独立的标题重写规则系统负责。

### 标题重写规则冲突

规则采用保守冲突校验：

- 对相同精确 URL 执行准确检测并阻止保存；
- 对相同正则表达式、相同固定前缀等明确冲突阻止保存；
- 对不能可靠判定交集的正则组合，显示“可能重叠”警告，允许用户确认继续保存。

### 标题重写的执行时机

标题重写规则默认自动运行，每条规则可切换为仅手动运行。

自动规则仅在页面加载完成或 URL 变化时应用一次；不监听标题/favicon 的后续变更，不与网站脚本持续争夺控制权。

### 重启后的槽位恢复

浏览器重启导致 `tabId` 失效后，不做后台预扫描。用户首次触发槽位时，插件按已配置 URL/正则和匹配策略搜索已打开标签页；成功切换则自动将槽位的 `tabId` 更新为新目标。

## 关键取舍

- 多窗口体验列为首版关键能力，增加实现与测试范围，但符合标签页快速切换的实际桌面使用环境。
- 页面改写采取一次性执行，优先低性能开销和可预期边界，不承诺抵抗网站后续重写。
- 对复杂正则无法做数学上完备的交集分析；以明显冲突阻止、潜在冲突告警确认实现可用的安全折中。
